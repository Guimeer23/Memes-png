# Testes

Registrar e executar testes antes de cada publicação:
- O álbum abre e as imagens carregam.
- O login Google funciona.
- O inventário carrega para o usuário correto.
- Venda falha com segurança se a figurinha não pertence ao usuário.
- Troca não pode concluir duas vezes nem duplicar/remover itens incorretamente.
- Regras de acesso bloqueiam alterações não autorizadas.
